# Code of conduct

This applies to issues, pull requests, discussions and any other KAERIS project space.

## Expected

- Be respectful and assume good intent. Many people here write in their second language.
- Stay on topic. Critique code and ideas, not people.
- Give enough detail for others to help: version, command, output.

## Not accepted

- Harassment, insults, discriminatory remarks, sexual content, threats.
- Publishing someone else's private information, including API keys found in a log.
- Spam and advertising unrelated to the project.

## Enforcement

Maintainers may edit or remove content, lock threads, and block accounts that break these rules.
Report a problem to **support@kaeris.dev** with "Conduct" in the subject line. Reports are
handled privately, and we reply within 3 working days.
